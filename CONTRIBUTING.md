# 🤝 Contributing to GPT ASTRA 2.0
We welcome contributions from researchers, engineers, and cognitive scientists.

## 🛠️ How to Contribute
1. **Cognitive Modules**: Propose new methods for Perception or Reflection.
2. **Tool Expansion**: Add tools to `core/tools/lib`. All tools must pass the `ToolSecurityScanner`.
3. **Bug Reports**: Provide a `CognitiveState` dump of the failure.

## 📜 Quality Standards
- All PRs must include unit tests.
- Must pass the `AutoArchitect` efficiency review.
- Must be compatible with the `KnowledgeGraph` schema.
